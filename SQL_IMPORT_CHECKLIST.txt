TROUBLESHOOTING:

Problem: Cannot find phpMyAdmin
Solution: 
  1. Login to cPanel
  2. Search "phpMyAdmin" in cPanel search bar
  3. Or go to: Databases > phpMyAdmin

Problem: "Access Denied" during import
Solution:
  1. Verify user asiment3_zones exists
  2. Check user has all privileges on asiment3_electrobd
  3. Go to cPanel > MySQL Databases > check privileges

Problem: Import hangs/takes too long
Solution:
  1. Split larger files manually (not recommended)
  2. Contact hosting support
  3. Try importing during off-peak hours

Problem: "Syntax Error" in SQL
Solution:
  1. File may be corrupted
  2. Download fresh copy from project
  3. Verify file is UTF-8 encoded
