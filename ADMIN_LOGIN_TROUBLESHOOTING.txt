╔════════════════════════════════════════════════════════════════════════════════╗

Request Flow:
  1. Flutter: POST /auth/admin-login
  2. App converts to: /auth/admin-login.php
  3. Backend file: /backend/api/auth/admin-login.php
  4. Receives JSON: {"username":"...", "password":"..."}
  5. Queries database for admin user
  6. Verifies password with bcrypt
  7. Generates JWT token
  8. Returns: {"token":"...", "user":{...}}
