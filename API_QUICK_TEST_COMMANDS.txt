SETTING JWT TOKEN (For Linux/Mac):
════════════════════════════════════════════════════════════════

1. Login and get token:
TOKEN=$(curl -s -X POST "https://electrozonebd.com/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"adminNoman@electrozonebd.com","password":"ElectroAdmin@2026"}' \
  | grep -o '"token":"[^"]*' | cut -d'"' -f4)

2. Use token in requests:
curl -X GET "https://electrozonebd.com/api/auth/me" \
  -H "Authorization: Bearer $TOKEN"

COMMON ISSUES & SOLUTIONS:
════════════════════════════════════════════════════════════════

Problem: "404 Not Found"
Solution:
  1. Check URL spelling
  2. Verify API is running: https://electrozonebd.com/api/health
  3. Check .htaccess exists in /api folder
  4. Ensure mod_rewrite is enabled

Problem: "401 Unauthorized"
Solution:
  1. Include Authorization header with JWT token
  2. Token format: "Authorization: Bearer YOUR_TOKEN"
  3. Verify token is valid (check expiration)

Problem: "CORS Error"
Solution:
  1. This is normal for browser requests from different domain
  2. Flutter app won't have this issue
  3. Check .htaccess has CORS headers

Problem: "500 Internal Server Error"
Solution:
  1. Check server error logs on cPanel
  2. Verify database connection
  3. Check .env file has correct credentials
